# Decisions

## 2026-09-05 — Playable browser demo approved

사용자가 세 가지 구현 선택지 중 추천한 2안에 동의했다. React + Phaser로 UI와 보행 경험을 확인한다. PRD의 최종 Godot 모바일 엔진 결정은 변경하지 않는다.

## A small original neighborhood — initial demo, superseded 2026-09-06

지도·건물·장소명·소개는 가상의 샘플이다. 실제 성수의 지리 검증, OSM 데이터 추출, 분기별 데이터 조인은 수행하지 않는다. PRD의 범위 정의가 같은 문서의 서울숲·뚝섬한강공원 좌표와 어긋나는 점은 본 지도 제작 전에 해결해야 한다.

다섯 장소와 코스 하나를 끝까지 경험할 수 있는 범위를 택했다. 아트는 직접 그린 픽셀 자산이고 외부 사진이나 브랜드 자산을 사용하지 않는다. 사진 준비 상태를 명확히 표현하며 3D 탭으로 작동하지 않는 기능을 제시하지 않는다.

## React for UI, Phaser for the world

Phaser는 안정된 3.90.0으로 고정했다. React 19·Vite 8·TypeScript 5.9를 사용한다. 엔진 코드는 동적으로 불러온다. Vite 8의 기본 코드 분할을 사용하며 구형 Rollup 객체형 manualChunks 설정을 사용하지 않는다.

Canvas 원본 아트와 게임 엔진 모두 로컬에서 실행한다. 의존성·폰트는 프로젝트에 설치한다. 런타임 외부 API, 로그인, Supabase, 실시간 위치정보, 사진 수집은 없다.

## Input and scene transitions

상세 화면은 불투명한 별도 화면으로 전환한다. 같은 Phaser 장면을 유지해 복귀 시 위치를 보존한다. 상세를 열 때 자동 이동을 중단하고 입력을 해제한다. 여권·소개·숨겨진 탭에서는 프레임 루프를 멈춘다. 모바일 방향 패드는 포인터 캡처를 사용하고 pointerup, pointercancel, 캡처 소실에서 입력을 해제한다.

## Storage and demo boundaries

도장은 실제 매장 방문이 아닌 가상 방문이다. 근접한 장소에서만 수집 가능하고 중복 발급은 없다. 데이터는 기기 내 브라우저에 저장한다. 전체 초기화는 사용자가 앱의 확인 창에서 선택해야 한다.

서비스 워커를 설치하지 않았으므로 오프라인 새 접속·재로딩은 보장하지 않는다. 실제 iOS·Android GPU 성능, 60fps 유지, 네이티브 앱 크기와 배포는 검증되지 않았다.

## 2026-09-06 — Real Seongsu Station neighborhood

사용자 요청에 따라 네이버 지도·공식 매장 정보를 조사하고 성수역 남쪽 연무장길 주변의 실제 다섯 장소로 교체했다. 지리 데이터는 정적 OSM 추출본을 투영해 사용하고, 건물·길 폭은 플레이를 위해 단순화한다. 외부 API 호출이나 키 없이 작동한다. 실제 주소·출처·네이버 링크·확인일을 상세에 제공한다. 개요 지도와 원본 픽셀 외관으로 기존 사진 준비 영역을 대체한다.

정확도 범위·선정 근거·데이터 라이선스는 [REAL_NEIGHBORHOOD.md](REAL_NEIGHBORHOOD.md)에 기록한다. 예전 가상 코스의 저장 키를 그대로 보존하고 실제 코스는 별도 키에서 시작한다. 신규 원격 push·PR·배포는 수행하지 않는다.
