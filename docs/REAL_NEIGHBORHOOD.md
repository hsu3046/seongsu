대림창고 카페와 무신사는 **별도 장소**다. 탬버린즈 연무장5길 매장과 뚝섬로의 하우스 노웨어도 구별한다. 단기 팝업·리뷰 평점·가격은 코스 데이터에 포함하지 않았다.

## 지도를 만든 방법

1. 네이버 지도와 공식 정보를 통해 코스와 상호·주소를 확인했다. 지도 타일, 로고 이미지, 리뷰 문장, 실사 사진은 가져오지 않았다.
2. [OpenStreetMap 공개 데이터](https://api.openstreetmap.org/api/0.6/map?bbox=127.0505,37.5403,127.0592,37.5466)를 조회해 화면에 필요한 도로 52개 way와 건물 288개 way를 추렸다. 도로 하나가 여러 way로 나뉠 수 있으므로 52개가 서로 다른 도로 수를 뜻하지는 않는다.
3. `src/data/map-source.json`에는 way ID와 경위도·필요한 이름만 보관했다. 편집자 계정 등은 포함하지 않는다. 원본 지도 데이터를 앱에서도 다운로드할 수 있다.
4. 경도 127.0545, 위도 37.5435 주변의 국소 미터 좌표를 3px/m로 투영한 뒤 반시계 방향 21° 회전했다. 성수역 앞 아차산로가 거의 수평이 된다. 월드는 1856×1376px이며 북쪽 방향을 개요 지도에 표시한다.
5. 도로 중심선과 연결, 매장 중심의 상대 위치를 유지한다. 보행 공간을 확보하도록 도로 폭·보도를 넓히고, 건물 윤곽은 중심을 유지한 채 축소한다. 렌더와 충돌 판정은 같은 축소 윤곽을 사용한다.

## 데이터와 저장

- 이 코스의 키: `seongsu-passport:yeonmujang:v1`.
- 예전 `seongsu-passport:v1` 여권은 덮어쓰거나 삭제하지 않는다. 예전 가상 장소 도장을 실제 매장 도장으로 바꾸지 않는다.

- 원본 프로그램·픽셀 묘화 코드는 기존 GPL-3.0-only. 지도 데이터의 라이선스를 GPL로 바꾸지 않는다.
- 외부 지도 API 키, 런타임 지도 호출, 백엔드, 신규 패키지는 필요하지 않다. 빌드에 포함한 정적 데이터로 작동한다.
