# Architecture

## Runtime

- src/App.tsx: 화면·언어·여권·즐겨찾기 상태와 사용자의 행동을 관리한다.
- src/components/WorldCanvas.tsx: Phaser를 지연 로드하고 생성·정리·리사이즈·페이지 가시성 신호를 연결한다.
- src/components/MapTools.tsx: 모바일 시간대·카메라 도구를 접고 펼친다. 바깥 터치는 투명 backdrop으로 닫으며 맵 이동으로 전달하지 않는다.
- src/hooks/useMapFullscreen.ts: 네이티브 전체 화면과 창 크기 보기를 연결하고, 종료 이벤트·스크롤·키보드 포커스를 복원한다.
- src/game/world.ts: Phaser 장면, 물리 충돌, 캐릭터, 카메라, NPC, 시간대, 장소 근접 감지를 담당한다.
- src/game/art.ts: 원본 픽셀 건물·도로·나무·소품·사람·강아지·스쿠터 및 장소 썸네일을 Canvas로 생성한다.
- src/game/navigation.ts: 건물 다각형·도로 통행 영역과 8px 격자의 4방향 길찾기를 제공한다.
- src/data/places.ts: 실제 다섯 장소의 ID·주소·출처·EN/JA 콘텐츠·지도 앵커·가상 도착점를 보관한다.
- src/data/geography.ts: OSM 경위도를 투영·회전하고 렌더/충돌용 건물 윤곽과 도로를 만든다.
- src/data/map-source.json: ODbL 라이선스의 정적 OSM 도로·건물 추출 데이터.
- src/data/copy.ts: EN/JA UI 문구. 일본어 사전의 키를 영어 사전과 타입으로 맞춘다.
- src/state/progress.ts: 저장 데이터 검증·초기화·수집·즐겨찾기의 순수 함수를 제공한다.
- src/styles.css: 데스크톱·모바일 화면과 접근성 상태를 구성한다.

## Frame ownership

프레임 루프는 Phaser 한 곳에서 소유한다. React는 매 프레임 좌표를 받지 않는다. 이동 위치는 약 1초마다, 그리고 화면을 떠나 일시정지할 때 받으며 변하지 않은 위치는 React 상태를 갱신하지 않는다.

맵을 떠나거나 문서가 숨겨지면 입력을 해제하고 물리와 엔진 루프를 함께 정지한다. 복귀 시 같은 장면을 다시 사용한다. 장소 상세 진입은 자동 보행도 중단한다. 전체 화면의 상세·여권·소개 화면에서는 맵 DOM을 숨겨 실사/상세 레이어 뒤에 노출하지 않는다.

Phaser의 destroy는 다음 프레임에 처리되므로, 이미 잠든 엔진을 정리할 때는 삭제 플래그 설정 후 루프를 한 번 깨운다. 방향키의 스크롤 취소는 Phaser의 키 캡처로 처리한다. Phaser보다 앞선 DOM 리스너에서 preventDefault를 호출하면 입력이 무시되므로 이중 키보드 처리기를 두지 않는다.

가까운 장소는 E 또는 Enter로 연다. Phaser의 공용 진입 처리기가 유효한 근접 상태에서만 기본 동작을 취소한다. 반복 입력·조합 중 입력·수정 키·텍스트 입력은 제외하고, Tab으로 선택한 UI의 Enter는 기본 버튼 동작을 유지한다. 도착 카드에 EN/JA 키 안내와 aria-keyshortcuts를 제공하며 터치 환경에서는 안내 문구를 숨긴다.

캐릭터 텍스처는 24×34px이며 정지 1장과 걷기 4장을 사용한다. 좌우는 좁은 몸통·코·귀·가방과 앞뒤 팔다리가 있는 측면 전용 그림을 좌우 반전한다. 보행 시간은 이동 속도에 비례해 진행하고 정지 시 초기화한다. 그림의 변경은 발의 원점과 10×8px 충돌 영역에 영향을 주지 않는다.

## World

전체 화면은 같은 map-frame과 Phaser 캔버스를 유지한 채 크기만 바꾼다. ResizeObserver에서 엔진 크기를 갱신하고 카메라를 플레이어에게 맞춘다. 상세 페이지로 이동하면 전체 화면을 종료한다. 모바일에서는 주소·좌표와 상시 도구 모음을 숨기고, 방향 아이콘의 보이는 원만 작게 그려 44px 터치 영역을 보존한다. 탐색 메뉴는 맵 아래 문서 흐름에 배치한다.

1856×1376 논리 픽셀의 실제 성수역 남쪽 구역이다. 약 3px/m로 투영하고 21° 회전한다. [조사와 정확도 범위](REAL_NEIGHBORHOOD.md)를 참고한다. 원본 OSM 데이터를 묘화할 때 보행 공간을 위해 도로 폭을 넓히고 건물 윤곽을 축소한다. 도로 중심선과 매장의 상대 위치는 유지한다. 맵은 한 번 만든 텍스처를 재사용한다.

물리 이동과 길찾기는 같은 도로 영역·건물 다각형을 참조한다. 8px 통행 격자를 지연 생성하여 재사용하고, 시작/끝 좌표까지의 연결 구간도 검사한다. 일반 입력은 자동 보행을 취소한다. Arcade의 고정 물리 스텝이 Scene.update보다 먼저 반영될 수 있으므로 예상 이동점과 실제 이동 결과를 모두 검사하고 마지막 통행 가능 위치를 보존한다. 도로 밖 블록은 걸을 수 없다. 의자·가로등 등 장식물은 별도 장애물로 다루지 않는다.

## Persistence

브라우저 localStorage 키는 seongsu-passport:yeonmujang:v1이다. 기존 가상 코스의 seongsu-passport:v1은 보존하고 읽거나 변환하지 않는다. 버전·장소 ID·열거값·좌표를 검증한다. 손상되거나 지원하지 않는 형식은 새 여권으로 대체하고 알 수 없는 장소와 중복 ID를 제거한다. 복원 좌표가 건물 안이면 엔진이 시작 지점으로 보정한다.

계정, 국적 추정, 원격 로깅, 개인 식별 정보 수집은 없다. 저장 실패 시 세션은 계속 사용할 수 있고 저장 불가 메시지를 표시한다. PWA 캐시는 구현하지 않았다.

## Migration

Godot로 옮길 때 장소 ID·번역·코스 순서·원본 아트 생성 규칙·건물 충돌 메타데이터를 참고할 수 있다. React 화면과 Phaser 장면 코드의 자동 이식은 전제하지 않는다.
