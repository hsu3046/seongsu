# Seongsu project memory

## 2026-09-05 — UI 데모 승인 및 첫 구현

- 입력은 doc/seongsu-app-prd.md. 사용자는 조사·계획을 요청한 후 추천 2안에 “좋아.”로 승인했다.
- React + TypeScript + Vite + Phaser의 로컬 브라우저 데모로 구현한다. 최종 Godot 앱 개발로 전환한 것은 아니다.
- 작은 가상 마을, 5개 장소, 코스 1개, EN/JA, 세 시간대, 방문 도장, 즐겨찾기, 로컬 저장이 범위다.
- 아트는 src/game/art.ts에서 직접 생성한다. 실사·3D 자산이 제공되지 않았으므로 사진은 준비 상태다.
- PRD의 지도 bbox는 문서에 적힌 서울숲·뚝섬한강공원 좌표와 일치하지 않는다. 실제 지도 파이프라인 전에 범위를 다시 확인한다.
- 첫 작업 시 Git 저장소가 아니었으며 공개 배포·원격 저장소 조작은 수행하지 않았다.
- Phaser는 프레임 루프를 소유하고 React는 저빈도 상태 이벤트를 받는다. 상세 진입·탭 숨김에서 입력과 렌더를 중지한다.
- 사용자 진행도는 seongsu-passport:v1. 가까이 방문한 장소에만 도장을 추가하고 손상된 저장 데이터는 검증해서 복원한다.
- 실행·검증 방법: docs/SETUP.md. 검증 결과: docs/VALIDATION.md.
- 빌드와 단위 테스트 6개, 주요 브라우저 검사 16개, 추가 입력·수명주기·반응형 검사 7개가 통과했다. 실제 휴대폰의 GPU·지속 성능은 검증하지 않았다.

## 2026-09-05 — 모바일 맵 집중 보기

- 사용자 요청: 전체 화면 버튼을 추가하고 휴대폰에서 맵을 가리는 아이콘을 줄인다.
- 같은 캔버스로 Fullscreen API와 창 크기 대체 보기를 제공한다. 종료 시 스크롤·포커스를 복원하고 상세 진입 시 전체 화면을 닫는다.
- 모바일 시간대·줌은 Map tools에 접는다. 주소·좌표는 숨기고 탐색 메뉴는 맵 아래에 둔다. 방향 아이콘은 작게 그리되 44px 터치 영역을 유지한다.
- 화면 리사이즈 후 카메라를 플레이어에게 바로 맞춘다. 전체 화면 상태는 진행도 저장에 포함하지 않는다.
- 검증 스크립트: tests/fullscreen.mjs. 실제 iOS 기기 검증은 별도 필요하다.
- 전체 화면 종료 시 자동 복원된 focus가 주황색 원으로 남았다. 앱에서 Tab 탐색 여부를 명시하고 pointer 입력 시 해제해, 클릭·탭과 게임 이동 키가 포커스 테두리를 남기지 않도록 했다. 인앱 브라우저에서 전체 화면 종료·Tab·후속 클릭을 확인했다.

## 2026-09-06 — 실제 성수역 남쪽 코스

- 사용자 요청으로 네이버 지도와 공식 매장 안내를 조사해 실제 구역을 구현했다. 쎈느 → 디올 → 탬버린즈 → 대림창고 갤러리 → 무신사 성수, 역 4번 출구에서 시작한다.
- 1856×1376px, 약 620×460m. OSM 경위도를 3px/m와 -21° 회전으로 투영한다. src/data/map-source.json은 ODbL 데이터이며 앱의 출처 표시·다운로드 링크를 유지한다.
- 도로 중심선과 상대 위치를 유지하고, 길 폭·건물 윤곽은 게임용으로 조정한다. 출입문 실측이 아닌 도로 위 가상 도착점이다. 무신사는 두 창고 윤곽에 연결한 근사 위치다. 세부 근거: docs/REAL_NEIGHBORHOOD.md.
- 실제 키는 seongsu-passport:yeonmujang:v1. 예전 가상 키 seongsu-passport:v1을 덮어쓰거나 삭제하지 않는다.
- 실제 장소 ID: scene, dior, tamburins, daelim, musinsa. 모든 매장에 실제 주소·정확한 네이버 플레이스 ID·출처·확인일이 있다. 대림창고 카페(78)와 무신사(74), 탬버린즈 성수와 하우스 노웨어는 구별한다.
- 8px 길찾기 격자와 실제 이동이 같은 도로/건물 다각형 판정을 사용한다. Phaser 고정 물리 스텝이 Scene.update 전 반영되므로 예상 좌표만 검사하면 충돌 경계가 새어 나간다. 실제 위치도 검사해 마지막 안전 위치로 복원한다.
- 빌드, 단위 7개, 브라우저 17개, 입력 7개, 전체 화면 8개, 주소 링크·전체 화면 출처 Tab 검사 통과. 실제 폰 검증은 별도다.
- 새 코스는 로컬 브랜치 codex/real-seongsu-neighborhood. 이번 요청으로 새 push/PR/merge/배포는 하지 않는다. 사용자 생성 .Codex/config.toml은 건드리지 않는다.

## 2026-09-06 — 측면 보행·키보드 장소 진입

- 좌우 걷기가 정면 몸통·다리를 재사용하던 것을 측면 전용 실루엣과 4단계 보행으로 변경했다. 정지 프레임은 별도이며 24×34px 캔버스·발 원점·충돌 크기를 유지한다.

- 진입은 근접 상태에서만 처리한다. 반복·조합·수정 키·텍스트 입력을 제외하며 Tab으로 선택한 UI 버튼의 Enter 동작을 유지한다. 유효한 게임 Enter는 이전에 클릭해 포커스가 남은 버튼의 기본 동작을 취소한다.
- 빌드·단위 7개·기존 입력 7개·신규 키보드 진입 7개 검사 통과. 전체 화면 진입, 다섯 장소, 키를 누른 채 복귀, Tab 탐색, 모바일 탭을 검증했다. tests/keyboard-entry.mjs 참조.
