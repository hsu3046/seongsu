# Seongsu project memory

## 2026-09-05 — UI 데모 승인 및 첫 구현

- 입력은 doc/seongsu-app-prd.md. 사용자는 조사·계획을 요청한 후 추천 2안에 “좋아.”로 승인했다.
- React + TypeScript + Vite + Phaser의 로컬 브라우저 데모로 구현한다. 최종 Godot 앱 개발로 전환한 것은 아니다.
- 작은 가상 마을, 5개 장소, 코스 1개, EN/JA, 세 시간대, 방문 도장, 즐겨찾기, 로컬 저장이 범위다.
- 아트는 src/game/art.ts에서 직접 생성한다. 실사·3D 자산이 제공되지 않았으므로 사진은 준비 상태다.
- PRD의 지도 bbox는 문서에 적힌 서울숲·뚝섬한강공원 좌표와 일치하지 않는다. 실제 지도 파이프라인 전에 범위를 다시 확인한다.
- 첫 작업 시 Git 저장소가 아니었으며 공개 배포·원격 저장소 조작은 수행하지 않았다.
- Phaser는 프레임 루프를 소유하고 React는 저빈도 상태 이벤트를 받는다. 상세 진입·탭 숨김에서 입력과 렌더를 중지한다.
- 사용자 진행도는 seongsu-passport:v1. 가까이 방문한 장소에만 도장을 추가하고 손상된 저장 데이터는 검증해서 복원한다.
- 실행·검증 방법: docs/SETUP.md. 검증 결과: docs/VALIDATION.md.
- 빌드와 단위 테스트 6개, 주요 브라우저 검사 16개, 추가 입력·수명주기·반응형 검사 7개가 통과했다. 실제 휴대폰의 GPU·지속 성능은 검증하지 않았다.

## 2026-09-05 — 모바일 맵 집중 보기

- 사용자 요청: 전체 화면 버튼을 추가하고 휴대폰에서 맵을 가리는 아이콘을 줄인다.
- 같은 캔버스로 Fullscreen API와 창 크기 대체 보기를 제공한다. 종료 시 스크롤·포커스를 복원하고 상세 진입 시 전체 화면을 닫는다.
- 모바일 시간대·줌은 Map tools에 접는다. 주소·좌표는 숨기고 탐색 메뉴는 맵 아래에 둔다. 방향 아이콘은 작게 그리되 44px 터치 영역을 유지한다.
- 화면 리사이즈 후 카메라를 플레이어에게 바로 맞춘다. 전체 화면 상태는 진행도 저장에 포함하지 않는다.
- 검증 스크립트: tests/fullscreen.mjs. 실제 iOS 기기 검증은 별도 필요하다.
